# Café Aurora – Modern Café Portfolio Website

A clean and fully responsive café-themed portfolio website featuring elegant UI design, smooth animations, and a professional layout inspired by real café branding.

## 🌟 Features
- Fully responsive (mobile, tablet, desktop)
- Minimal and modern café UI/UX
- Smooth animations and transitions
- Hero section with call-to-action
- Menu section with pricing
- About + Services sections
- Contact section
- Organized, scalable code structure

## 🛠 Built With
- HTML5  
- CSS3  
- JavaScript  

## 🚀 How to Use
1. Download or clone this repository:
2. Open `index.html` in any modern browser.
3. Customize the images, text, or colors as needed.
